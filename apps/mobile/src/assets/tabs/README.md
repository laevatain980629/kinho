# TabBar 图标

需要准备以下 PNG 图标文件（81x81px，透明背景）：

| 文件名 | 用途 |
|--------|------|
| home.png | 首页（未选中） |
| home-active.png | 首页（选中） |
| order.png | 工单（未选中） |
| order-active.png | 工单（选中） |
| approval.png | 审批（未选中） |
| approval-active.png | 审批（选中） |
| warehouse.png | 仓库（未选中） |
| warehouse-active.png | 仓库（选中） |
| profile.png | 我的（未选中） |
| profile-active.png | 我的（选中） |

未选中颜色：#999999
选中颜色：#333333
